# For My Favorite Person 💖

A small, personal love-letter website with interactive memories, a shared-future bucket list, and a love meter.

## Open the website

Open `index.html` in a web browser. No build tools or installation are required.

The page loads Google Fonts and Font Awesome from their CDNs, so an internet connection is needed for those fonts and icons. The rest of the site is local.

## Project files

- `index.html` contains the page content and structure.
- `styles.css` contains the layout, colors, animations, and responsive styling.
- `script.js` powers the letter prompts, flip card, bucket list, and love meter.

## Interactive features

- Tap the envelope to go through the prompts and open the letter.
- Flip the “Meeting at School” card to reveal the story, and flip the “Little Things I Love About You” cards to read their messages.
- Check off bucket-list ideas or add new ones. Added ideas are saved in this browser using local storage; they do not sync between devices or browsers.
- Tap the heart in the love meter to add 100% and release falling hearts. The meter resets when the page reloads.

## Customize the page

Edit the text in `index.html`, the appearance in `styles.css`, and the interactions in `script.js`.
